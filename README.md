# 遊戲測試｜2.5D 純網頁遊戲

這是一個不需要後端、資料庫、帳號或遊戲存檔的前端小型遊戲。以 Canvas 2D 繪製簡易 2.5D 風格場景，使用原生 JavaScript 控制角色、敵人、攻擊判定與波次。

## 放到 GitHub Pages

1. 建立一個 GitHub repository。
2. 將 `index.html`、`style.css`、`game.js`、`README.md` 放到 repository 根目錄。
3. 進入 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 中選擇 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 `/(root)`，按 Save。
6. 等待 GitHub Pages 部署完成後，開啟它提供的網址。

也可以先直接雙擊 `index.html` 在本機測試。此版本不需要 npm、打包器或伺服器。

## 操作

- `W A S D`：移動
- `Space`：短距離衝刺，預設冷卻 4 秒；衝刺期間短暫無敵
- `Shift`：閃避無敵，預設持續 1 秒、冷卻 8 秒
- 滑鼠左鍵：三段一般攻擊，傷害逐段提高；中途衝刺、閃避或使用特殊攻擊會重置連段
- 滑鼠右鍵：範圍波動，傷害並擊退周圍敵人
- `Esc`：暫停／繼續

## 已實作內容

- 開始畫面、說明頁、可調參數設定頁
- 青色主角、紅色一般敵人、紫色首領
- 2.5D 風格地面網格、角色陰影、簡易角色圖形
- 小地圖顯示敵人方向
- 敵人進入偵測距離後追擊，接近後停止並使用地面紅色攻擊預告
- 圓形、前方扇形、狹長直線三種攻擊區域
- 一般敵人每次一種攻擊；首領可輪替使用多種攻擊
- 每三隻一般敵人後出現首領
- 擊敗敵人取得經驗值、升級選能力；首領擊敗額外獲得一次能力強化
- 敵人血量、攻擊力與攻擊範圍隨波次成長
- 血量歸零結算畫面，按確認返回主畫面
- 設定可調整衝刺／閃避／攻擊冷卻、敵人前搖、偵測距離、初始血量與攻擊力、難度倍率

## 目前的簡化與限制

- 所有遊戲邏輯都在瀏覽器端執行；這是原型，不是具完整動畫、音效、手把支援或伺服器驗證的正式遊戲。
- 不會儲存進度；重新整理頁面就會重置。
- 角色與場景是 Canvas 繪製的簡易圖形，不使用 3D 模型或外部素材。
- 「2.5D」是斜俯視風格的 2D 繪製，並非真正的 WebGL 3D 場景。
- 設定頁數值會在目前頁面套用；開始遊戲時讀取設定。
